# 🔗 Conseguir tu URL pegable en 5 minutos

> Sin APK, sin app stores, sin programar. Solo una URL.

---

## La forma más fácil: Vercel drag-and-drop

### Paso 1 · Crear cuenta (2 min)

1. Abre **[vercel.com/signup](https://vercel.com/signup)** en tu navegador
2. Pulsa **"Continue with Email"**
3. Escribe tu email → te llega un código → mételo
4. Te pregunta tu nombre → escríbelo → **Continue**
5. Te pregunta el plan → elige **"Hobby"** (el GRATIS, dice $0/month)
6. ✅ Ya estás en el dashboard

### Paso 2 · Subir la app (3 min)

1. En el dashboard, pulsa el botón **"Add New..."** arriba a la derecha
2. Pulsa **"Project"**
3. Verás un cuadro grande. Busca abajo donde dice **"Or, deploy a folder"** o el área de drag-and-drop
4. **Arrastra la carpeta `spiritpet` entera** ahí

   Si no la tienes descomprimida: descomprime `spiritpet-todo-listo.zip` primero. Necesitas la carpeta entera, no archivos sueltos.

5. Vercel detecta los archivos automáticamente
6. Te pregunta el nombre del proyecto → escribe lo que quieras (ej: `spiritpet`)
7. Pulsa **"Deploy"**
8. Espera 30 segundos

### Paso 3 · Conseguir tu URL

Aparecerá una pantalla de éxito con tu URL:

```
https://spiritpet-xxxxxx.vercel.app
```

**Esa es tu URL pegable. ¡Listo!**

### En YouTube
- En la **descripción**: pega la URL directa
- En **comentario fijado**: "👇 Pruébalo aquí: [URL]"
- En **tarjetas/end-screens**: añade el link

### En Telegram/WhatsApp
- Manda la URL y se previsualiza con el icono del fantasma

### Convertirla en más bonita (opcional)
Si quieres una URL más corta tipo `spiritpet.app`, puedes:
- **Bit.ly** (gratis): te da `bit.ly/spiritpet`
- **Comprar dominio** (10€/año): `spiritpet.es` apuntando a tu Vercel
   - Compras dominio en Namecheap o Hostinger
   - En Vercel → Settings → Domains → añadir tu dominio
   - Vercel te dice qué configurar en el panel del dominio (1 click normalmente)

## Cuando los usuarios abren la URL

### En iPhone (Safari)
- La web carga
- A los 45 seg aparece automáticamente un banner: **"Instalar SpiritPet"**
- El banner les explica: pulsa Compartir ⎙ → "Añadir a Inicio"
- Si la instalan: aparece como app real, pantalla completa, funciona offline

### En Android (Chrome)
- La web carga
- A los 30 seg aparece banner automático **"Instalar"** con botón
- Si pulsan: se instala como app real

### En cualquier ordenador
- Se abre como web normal
- En Chrome también pueden instalarla (ícono de instalación en la barra de direcciones)

**Conclusión: una URL que se comporta como web Y como app instalable. Lo mejor de los dos mundos.**

## ¿Y si quiero actualizar la app?

Tienes 2 opciones:

### Opción A: Re-subir desde Vercel (lo mismo de antes)
1. Vuelves a Vercel
2. Vas a tu proyecto
3. Settings → o directamente "Redeploy" arrastrando carpeta nueva

### Opción B: Conectar con GitHub (recomendado a futuro)
1. Subes el código a GitHub una vez
2. Cada cambio = `git push` y se despliega solo
3. Los usuarios reciben la actualización en su siguiente apertura

---

## ❓ Si algo va mal

- **"No veo dónde arrastrar la carpeta"**: en Vercel, después de pulsar Add New → Project, busca un texto pequeño que dice "Try Vercel CLI or deploy a folder" — pulsa "deploy a folder"
- **"Me pide GitHub"**: puedes saltarlo. Busca abajo "Deploy without Git"
- **"No me deja arrastrar la carpeta"**: prueba con el navegador Chrome o Edge. Safari a veces tiene problemas
- **"Tarda mucho"**: normal la primera vez, ~30-60 segundos
